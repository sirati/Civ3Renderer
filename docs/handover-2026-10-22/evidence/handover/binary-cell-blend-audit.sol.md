# Native 4K GPU audit and isolated binary-cell candidate

The latest available actual-App performance evidence is the 866 run, not current 9b/8b. Its sampled window GPU frame medians range from 18.60 to 19.27 ms. Grouped map views v0 and v1 cost 4.23–4.66 and 4.49–4.67 ms, with output at 1.79–1.90 ms. Timing coverage is incomplete and all three runs fail the stronger sustained-motion qualification. Their raw 45–47 FPS is not a qualified dynamic result.

The older split-pass native 4K backend diagnostic identifies terrain as its largest stage at 3.393 ms, followed by the 49-layer detail pass at 2.654 ms, fog at 2.174 ms, output at 1.784 ms and clear at 0.438 ms. These are historical raster-text/two-camera diagnostic results, not current App timings. Accepted Tiles555 reduced a separate same-binary native GPU median from 12.249 to 11.115 ms. Generic indexed-opaque, forced-quads, float-only output decode and dense-resolve experiments were rejected and should not be repeated as new findings.

Current ordinary map steps already share one render pass per view. Diagnostic per-step timestamps split them deliberately. Native palette smoke snapshots only visible affected rectangles and preserves ordered destination composition. Retained-background capture and restoration copy the full canvas conditionally. Capture still occurs with frame reuse disabled when trailing overlays need a saved background. One 4K RGBA8 canvas is 33,177,600 bytes, but this count is not a measured timing saving. The old two-camera backend fixture has no trailing overlay camera, so this capture cannot explain its baseline. A current App pass analysis should distinguish such unlabelled copies from shader spans.

Four synchronous atlas compatibility/retirement sites contain `wait_indefinitely`; the normal worker and timestamp polling are nonblocking, and live art transfers use the bounded asynchronous path. No measured steady frame delay has been attributed to those compatibility calls. No wait was removed during this audit.

The isolated prototype is under `/mnt/datasets/c3r-build/binary-cell-blend-sol/source`, derived from immutable 8b. It changes only the renderer host file and adds a private binary-cell helper/test module. Existing shader sources, formats, indexed geometry and cell-major layer order remain unchanged. A once-read `TILE_RENDER_BINARY_CELLS=1` toggle, off by default, permits `blend=None` only after every reachable LUT set, animation frame and downscaled descriptor proves alpha 0/255. Existing alpha-zero discard preserves holes; opaque fragments replace RGB and target alpha exactly. Atlas/palette descriptor refresh and world/LUT/set replacement rebuild certificates. No CPU pixel rendering, new GPU readback, pass, copy or barrier is added.

The initial scope is native zoom 1/1, downscale 1, art stage 0, no scaled origin, no stacked camera, and ordinary direct or quantized target paths. Internal-source composition is excluded. Three variants cover direct, generic quantized and Tiles555. RGB666/RGB777, integer-FP16, scaled cameras, scale layers, translucency and unknown certificates retain the original paths. Vanilla loader-option inspection finds binary alpha for all 20 terrain/polar/flood image sources, but actual eligibility still requires the descriptor certificate.

Seven authored regressions cover all animation/twin descriptors, every LUT value and unknown records, out-of-scope camera rejection, strict independent integer direct/RGB444/RGB555 pixels with holes and ordered overlap followed by fog, named-palette/RGBA/atlas invalidation, world/set/twin replacement, and three queued control snapshots. The RGB555 integer test exercises both generic and Tiles555 selectors. The shared/GPU-text/production/unit builds pass, and all three CPU certificate/native-scope tests pass. Four GPU regressions now pass with four native and four feature-free executions under WGPU validation on AMD RADV PCI `0000:72:00.0`. The independent strict integer oracle checks 3,456 pixels per device path, 6,912 total, including all three pipeline variants and both RGB555 selectors. Palette/RGBA/atlas, LUT/set/twin, and three-control-slot cases pass. No test is ignored.
